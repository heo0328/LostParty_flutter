# MVP 정의 - LOSTPARTY

## 🎯 목적
최소 기능으로 실제 동작 가능한 앱을 만든다.

---

## 📌 MVP 범위

현재 MVP는 아래 기능으로 제한한다:

1. 캐릭터 인증 (간단 버전)
2. 모집글 목록 조회
3. 모집글 작성
4. 모집글 지원

---

## ❌ MVP 제외 기능

초기에는 구현하지 않는다:

- 알림 시스템
- 그룹 기능
- 채팅
- 소셜 로그인
- 복잡한 필터
- 추천 시스템
- 자동 숙제 체크

---

## 📌 개발 원칙

- 한 번에 큰 기능 구현 금지
- 기능은 반드시 단계별로 구현
- 구조(MVVM)는 유지
- 확장 가능성은 고려하되 미리 구현하지 않는다

---

## 📌 첫 구현 대상

👉 모집글 목록 기능
