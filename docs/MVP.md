# MVP (2026)

## 📌 프로젝트
LOSTPARTY  
로스트아크 레이드 파티 모집/지원 앱

---

## 🎯 MVP 목표

최소 기능으로 실제 사용 가능한 모집/지원 흐름 구현

---

## 📦 MVP 기능 범위

### 1. 모집글 목록
- 모집글 리스트 조회
- 카드 형태 UI
- 기본 정보 표시
  - 레이드
  - 관문
  - 인원 상태
  - 역할 모집 상태
  - 숙련도
  - 시작 시간

---

### 2. 모집글 작성
- 레이드 선택
- 난이도 선택
- 관문 범위 선택 (start ~ end)
- 역할 구성 설정 (딜러/서폿)
- 최소 전투력 설정 (미입력 시 제한 없음)
- 숙련도 선택 (5단계 또는 제한 없음)
- 시작 시간 설정
- 최대 플레이 시간 설정 (null = 클리어시)

---

### 3. 모집글 지원
- 모집글 상세 확인
- 서버 검증 기반 지원
- 파티장 승인 또는 승인 없이 바로 가입
- 승인 후 조건을 충족하는 자기 캐릭터로 추가 승인 없이 교체
- KST 수요일 오전 6시 기준 캐릭터별 동일 레이드 주간 귀속
- 승인된 파티원 누구나 한 번의 조작으로 파티 완료 선언

### 4. 내 파티
- 내가 창설·가입·신청 중인 파티 구분
- 파티 구성, 신청 상태, 캐릭터 교체 및 완료 상태 확인

### 5. 계정 그룹
- 사용자 ID 검색과 그룹 초대
- 상대방 수락 기반 가입
- 그룹 전용 모집글 목록
- 그룹 멤버 수 제품 제한 없음

---

## ❌ 제외 기능 (MVP 이후)

- 채팅 기능
- 실시간 알림
- 친구/길드형 부가 기능
- 관리자 페이지
- 그룹 관리자 계층 등 복잡한 권한 시스템

---

## 📌 핵심 UX 목표

- 빠르게 조건에 맞는 파티 찾기
- 역할(딜러/서폿) 기준 필터링
- 최소한의 입력으로 모집글 작성

---

## 📌 데이터 설계 핵심

- RaidBase / RaidVariation 분리

- 필터링 가능한 데이터는 모집글에 포함
- maxPlayHours 기반 트라이 시간 관리
