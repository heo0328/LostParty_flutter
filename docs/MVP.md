# MVP (2026)

## 📌 프로젝트
LOSTPARTY  
로스트아크 레이드 파티 모집/지원 앱

---

## 🎯 MVP 목표

최소 기능으로 실제 사용 가능한 모집/지원 흐름 구현

---

## 📦 MVP 기능 범위

### 1. 모집글 목록
- 모집글 리스트 조회
- 카드 형태 UI
- 기본 정보 표시
  - 레이드
  - 관문
  - 인원 상태
  - 역할 모집 상태
  - 숙련도
  - 시작 시간

---

### 2. 모집글 작성
- 레이드 선택
- 난이도 선택
- 관문 범위 선택 (start ~ end)
- 역할 구성 설정 (딜러/서폿)
- 최소 전투력 설정
- 숙련도 선택 (5단계 고정)
- 시작 시간 설정
- 최대 플레이 시간 설정 (null = 클리어시)

---

### 3. 모집글 지원
- 모집글 상세 확인
- 지원 기능 (단순 MVP 수준)

---

## ❌ 제외 기능 (MVP 이후)

- 채팅 기능
- 실시간 알림
- 친구/길드 시스템
- 관리자 페이지
- 복잡한 권한 시스템

---

## 📌 핵심 UX 목표

- 빠르게 조건에 맞는 파티 찾기
- 역할(딜러/서폿) 기준 필터링
- 최소한의 입력으로 모집글 작성

---

## 📌 데이터 설계 핵심

- RaidBase / RaidVariation 분리
- 모집글은 raidId 참조 구조
- 필터링 가능한 데이터는 모집글에 포함
- maxPlayHours 기반 트라이 시간 관리
