# 디테일 개선 항목

앱의 핵심 기능과 별개로 사용 중 발견한 UI·UX 보완 사항을 기록한다. 각 항목은 관련 기능 작업 시 우선순위를 다시 판단한다.

## 완료 참가자 평가와 한마디

- 같은 파티 회차를 함께 완료한 사실이 확인된 Player 사이에서만 평가를 허용하는 방향을 검토한다.
- 상대에게 한마디 평가 또는 평점을 남기는 기능을 후속 후보로 둔다.
- 평가 자격을 증명할 최소 서버 데이터가 필요할 수 있다.
- 악용, 보복 평가, 반복 평가와 다중 계정 조작 방지 정책이 필요하다.
- 공개 범위, 익명성, 수정, 삭제, 신고와 이의 제기 정책을 별도로 정한다.
- 초기 Firebase 전환에서는 구현하지 않고 별도 제품 설계 후 범위를 확정한다.

현재 종료된 1회성 파티 원본과 완료 회차 Snapshot은 28일 보관하고 반복 파티방은 해산할 때까지 유지한다. 평가 기능에 필요한 최소 완료 증명의 장기 보관 여부는 평가 기능 설계 시 결정한다.

## 모집 생성

- 모집 생성 화면에서 내 계정 페이지로 이동해 캐릭터 표시, 대표 캐릭터 또는 저장 세팅을 변경한 뒤 복귀하면 후보 목록이 즉시 최신화되지 않는다.
- 화면 복귀 감지 또는 명시적인 새로고침 동작을 연결한다.

## 참가 일정

- 참가 일정 입력과 충돌 안내의 구체적인 제품 흐름을 별도로 기획한다.
- 기획 전까지 일정 관련 Domain 코드는 유지하되 현재 앱 UI와 로컬 참가 확정 판정에서는 비활성화한다.

## 파티 구성과 가입 조건

- 모집 상세에서 파티장이 파티원의 파티 및 슬롯 위치를 직접 조정할 수 있어야 한다.
- 8인 레이드는 4인 파티 두 개의 시너지 조합을 확인할 수 있도록 파티별 배치를 명확히 제공한다.
- 모집 중 남은 슬롯의 가입 조건을 직업 또는 시너지 기준으로 변경할 수 있어야 한다.

## 파티 신청 대기와 자동 취소

- 파티 신청 후 파티장 응답을 기다리는 유효 시간을 정의한다.
- 신청 유효 시간은 전체 공통값, 파티장 설정값 또는 모집별 설정값 중 어떤 방식으로 제공할지 기획한다.
- 제한 시간이 지나면 신청을 자동 취소할지, 만료 상태로 남겨 재신청을 허용할지 결정한다.
- 자동 취소 또는 만료 전에 신청자에게 남은 시간과 예정 동작을 명확히 안내한다.
- 파티장이 모집을 마감·취소하거나 가입 조건을 변경했을 때 대기 중인 신청을 유지할지 일괄 취소할지 규칙을 정의한다.
- 신청 취소, 자동 만료, 파티장 거절 및 모집 마감은 서로 구분되는 상태와 이력으로 기록한다.

## 참가자 수동 알림

- 모집 상세에서 파티장과 확정 파티원 모두 `알림 보내기` 버튼을 사용할 수 있어야 한다.
- 모집 내용 변경이나 참가 캐릭터 변경을 이유로 모든 참가자에게 자동 알림을 보내지 않고, 사용자가 필요할 때 수동으로 전송한다.
- 버튼을 누르면 `참가 인원에게 알림을 보냅니다.` 확인 알럿을 표시하고 확인한 경우에만 전송을 요청한다.
- 확인 후에는 전송 중 상태와 서버 기준 쿨다운을 적용해 연속 터치, 중복 전송 및 여러 기기에서의 우회를 방지한다.
- 실제 전송은 향후 Firebase 연결 시 인증된 서버 명령이 모집 참가 권한과 수신 대상을 검증한 뒤 FCM으로 처리한다.
- 발신자 본인은 수신 대상에서 제외하고 알림을 누르면 해당 모집 상세로 이동하도록 한다.

## 신청·가입 이후 변경

- 신청자는 승인 전까지 신청 캐릭터, 저장 역할 또는 신청 메시지를 수정할 수 있어야 하는지 결정한다.
- 신청 내용 수정 시 기존 신청의 대기 순서와 유효 시간을 유지할지 다시 시작할지 정의한다.
- 파티장은 모집 수정 화면에서 모집의 레이드와 난이도를 변경할 수 있어야 한다.
- 레이드 또는 난이도를 변경하면 현재 파티장과 모든 신청자·확정 파티원의 저장 세팅 아이템 레벨을 새 `minItemLevel` 기준으로 즉시 다시 판정한다.
- 변경된 레이드·난이도에 입장할 수 없는 파티원은 파티 구성과 모집 수정 화면에서 경고 아이콘과 사유를 함께 표시해 파티장이 명확히 식별할 수 있어야 한다.
- 입장 불가능 상태가 된 신청자나 확정 파티원을 자동으로 제외하거나 다른 캐릭터로 교체하지 않고, 변경 확정 전 영향받는 인원과 후속 조치가 필요함을 안내한다.
- 가입 이후 캐릭터·역할 변경은 파티 구성, 주간 완료, 참가 충돌 및 가입 조건을 다시 검증한다.
- 파티장이 가입 이후 슬롯 위치, 요구 역할, 직업 또는 시너지 조건을 변경할 때 기존 파티원에게 미치는 영향을 안내한다.
- 조건 변경으로 기존 신청자나 파티원이 더 이상 조건을 충족하지 못하더라도 자동 퇴장시키지 않고 확인·동의 흐름을 우선 검토한다.
- 신청자와 파티장 양쪽에서 변경, 취소, 승인 및 거절 결과를 확인할 수 있는 상태 표시와 알림을 기획한다.

## 직업 시너지

- 변경 빈도가 낮은 직업별 인게임 시너지는 게임 카탈로그 코드로 관리한다.
- 가입 후보가 남은 슬롯의 요구 직업 또는 시너지를 충족하는지 판정한다.
- 모집 목록 필터에서 내 캐릭터의 직업 또는 시너지를 원하는 모집을 빠르게 찾을 수 있도록 활용한다.
- 파티장은 남은 슬롯마다 특정 직업, 직업군, 역할 또는 시너지 조건을 선택할 수 있어야 한다.
- 특정 직업 지정과 시너지 조건이 동시에 설정될 때 AND/OR 적용 방식과 우선순위를 명확히 정의한다.
- 동일 시너지 중복, 파티 단위 적용 범위 및 4인·8인 레이드의 파티별 시너지 판정을 구분한다.
- 신청 화면에서 선택 캐릭터가 조건을 충족하는 이유와 충족하지 못하는 항목을 함께 표시한다.

## 모집 목록 조건 필터

- 모집 목록에서 레이드·난이도·관문 외에 역할, 특정 직업 및 요구 시너지 조건으로 필터링할 수 있어야 한다.
- 내 표시 캐릭터 중 현재 모집 조건을 충족하는 캐릭터가 있는 모집만 보는 필터를 제공한다.
- 여러 직업 또는 시너지 조건 선택 시 모두 충족과 하나 이상 충족을 사용자가 구분할 수 있도록 한다.
- 파티의 현재 구성으로 이미 충족된 조건과 아직 필요한 조건을 구분해 필터 결과와 모집 카드에 표시한다.
- 모집 조건이 가입 이후 변경되면 목록·상세·신청 화면의 필터 판정이 동일한 기준으로 즉시 갱신되어야 한다.
