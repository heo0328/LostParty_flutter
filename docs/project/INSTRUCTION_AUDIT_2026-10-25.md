# 작업 지시 문서 감사 — 2026-10-25

## 범위와 결론

감사 근거 행 번호는 정리 전6716325a를 기준으로 한다. 사용자 후속 설명에 따라 이번 정상화에서 초기 소셜로그인 금지/도구별 역할분리를 삭제하고 Git·설계/완료 조항을 교체했다. NEXT_WORK/AI_CONTEXT 원문은 history로 이관했다. 규칙을 상단에 덧붙이는 방식으로 처리하지 않았다. 항목8의 명시 규칙 존재를 암시한 표현은 아래에서 정정했다. 실제 B 앱 연결·Backend 규칙 변경은 이번 문서 정상화에 포함하지 않는다.

사용자 요청 순서대로 같은 feature/raid-recruitment-scheduling에서 실제 상태를 먼저 문서화하고 62ab9d6b로 커밋/푸시한 뒤 조사했다. 기능코드·서버/DB·dev/main은 변경하지 않았다. 감사 전 구현 기준은 B04098eae다. 감사 당시 발견과 수정 방향을 기록한 보고서다. 후속 핵심 실행 지침 정상화 결과는 위 상태와 DEV_LOG에 기록하며, 제품/API 세부 정책 전수 정리나 실제 B 연결 완료로 확대하지 않는다.

문서가 없어서 생긴 문제가 아니다. 정책09 D08에 2026-10-16부터 개발→베타→운영 방침이 명시돼 있고 AI_CONTEXT에도 존재했다. 이를 A/B 설계에 적용하지 않고 기본 legacy/별도 활성화를 도입한 것은 에이전트의 판단·검토 실패다. 아래 문서 구조 문제는 그 실패를 반복하기 쉬운 조건이며 사용자 승인이나 문서의 탓으로 책임을 바꾸는 근거가 아니다. 사용자의 기능 흐름 확인/진행 승인은 에이전트가 누락한 기본 조건을 검증했거나 기존 방침을 폐기했다는 의미가 아니다.

## 확인 근거와 수정 방향

### 1. 최우선 — 개발 방침은 있지만 자동 진입 게이트에 연결되지 않음

- 근거: [정책09 D08](../backend-migration/09-migration-decisions.md#d08-개발--베타--운영-데이터-수명--사용자-확정) 45~58행. '개발자료 보존형 이전/복원 리허설도 선행 조건이 아니다', 베타 직전 개발기록 삭제·베타 이후 보존을 명시한다. AI_CONTEXT '핵심 제품·자료 개념'에도 같은 방침이 있다.
- 반대 실행: 설계37 §37.68/37.69, 감사 전 NEXT_WORK는 운영 기본 legacy/활성화 후속을 기본 전제로 둔다. 실제 main.dart:7은 BackendApp()을 실행하고 backend_app.dart:99는 legacy다. 따라서 새 흐름은 일반 실행에서 선택되지 않는다.
- 정정: AGENTS의 구현 전 판단에 현재 개발 단계/09 D08 링크를 직접 둔다. 개발자료 호환을 위한 이중 운영·자료 변환·별도 활성화 단계를 필수화하지 않는다. API/DB 구조 버전 관리·현재 요청의 멱등/회원격리 같은 제품 정합성과 구자료 마이그레이션은 구분한다. 코드를 켜는 것만으로 끝내지 않고 연결된 전체 흐름을 확인할 수정 구간이 필요하다. 지금 데이터 삭제는 실행하지 않는다.

### 2. 최우선 — 실행계획이 확정 제품 방침보다 높게 배치됨

- 근거: ai_rules.md:238 / docs/README.md 관리 원칙은 NEXT_WORK·AI_CONTEXT를 제품/아키텍처 계약보다 앞에 둔다. AGENTS는 사용자 최신 지시 최우선을 명시하지만, 기록된 사용자 확정 정책을 계획에 대조하는 구체 게이트는 없다.
- 영향: 새 계획에 적었다는 이유로 이미 확정된 개발 방침을 덮고, 사용자의 진행 승인을 근거로 잘못된 기술 전제를 유지할 수 있다. 이번 A/B에서 실제 발생했다.
- 정정: 권한/규칙의 우선순위와 문서별 역할을 분리한다. 확정 사용자 정책은 기술 실행계획으로 변경할 수 없다. 계획 작성자가 제품 목표·개발 단계·운영/자료 수명·승인 UX·실제 완료 경로와의 일치를 확인한다. 사용자가 모든 기술 항목을 읽고 누락을 잡아야 하는 구조로 두지 않는다.

### 3. 높음 — '더 안전한 규칙'이라는 별도 우선순위

- 근거: docs/README.md:187은 AGENTS/ai_rules가 다르면 '더 안전한 규칙'을 우선하라고 하며 바로 아래에는 고정 우선순위가 있다.
