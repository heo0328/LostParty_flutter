# NEXT WORK — 주차별 레이드 그룹 변경·공대장 승계

## 목표·기준

2026-10-30 사용자 승인 계획을 실행한다. 현재 `feature/group-backend-integration`을 유지한다. 제품 계약은 [그룹 제품 §9](../product/GROUP_PRODUCT_FLOW.md#9-그룹-레이드-생성), 주차별 기술 계약은 [모집37](../backend-migration/37-raid-scheduling-and-multi-raid-planning.md#cycle-group-policy), 연결 책임은 [설계39](../backend-migration/39-group-flutter-integration-design.md)다.

일반→A 연결, A→B 교체, A→일반 연결 해제를 해당 주차 공대장이 수행한다. 일반은 연결 없음+전체 공개, 그룹은 한 그룹 연결+그룹 전용이다. C/N의 그룹·공개범위는 독립이며 제목 등 무관한 방 공통값까지 분리하지 않는다. 기존 참가·신청·배정·일정·예약·완료/기록을 보존한다. 탈퇴·직접 위임의 일반 전환/승계도 한 명령으로 원자 처리한다.
