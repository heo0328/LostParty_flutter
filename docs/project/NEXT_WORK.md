## 남은 작업 — 개발용 테스트 자료 준비 후 사용자 디바이스 확인

2026-11-09 사용자 결정으로 기기 테스트를 남은 작업으로 보관한다. 아래 항목은 아직 미확인이며 정상 인수로 처리하지 않는다. 이번 문서 정리/커밋/로컬 dev 통합에서 테스트 자료 조정이나 기기 시험은 실행하지 않는다.

경고·부분 완료 자료가 없는 구간은 미확인으로 남기고, 검증을 위해 실제 게임 캐릭터의 삭제·개명을 요구하지 않는다.

- 준비 담당: Native가 필요한 시나리오를 정리하고 Backend와 개발 전용 자료·재현/원복 절차를 협의한다. 본인 누락, 타인 누락/주차 권한, 일부 완료 후 누락을 준비 대상으로 한다. 구체 구현 방식은 미확정이며 서버/DB 조정은 별도 착수 범위다.
- 새로고침 경계: 게임 API를 다시 수집하면 인위적인 누락이 해제될 수 있으므로, 누락 유지와 동일 UUID 정상 복구를 각각 재현할 방법을 먼저 정한다. DB 상태만 바꿔 실제 수집·복구까지 검증했다고 취급하지 않는다.
- 검증 분담: Backend의 수집 누락 판정 자동 검증 근거와 Native의 서버 연동·화면 검증을 구분한다. 개발용 자료 준비 후 사용자가 아래 기기 항목을 확인하고 Native가 결과/미확인을 Issue17에 회신한다. 일반 정상 흐름도 사용자 결과 보고 전까지 미확인이다.
- 완료 조건: 준비한 자료/절차로 경고 발생·유지·복구, 권한, 부분 완료 기록 보존과 명시 변경/활동 관리 왕복을 확인하고 실패/미확인 항목을 기록한다. 이번 자동 검증 통과나 Git 보관으로 기기 인수를 대체하지 않는다.

1. 기존 정상 참가·신청·일정·완료·탈퇴와 이번주/다음주의 분리, 무변경 상세→목록 복귀 시 선택/스크롤 유지.
2. 누락 본인: 하단 좌상단 느낌표/우상단 사용량, 레이드 현황 주차/방 카드, 상세 주차 선택 아래 안내와 해당 원정대 갱신. 복구면 경고 해제, 지속 누락이면 기존 변경.
3. 타인 누락: 허용된 상세 주차/카드만 경고, 반대 주차 권한 없음은 정보 비공개. 본인 전용 갱신 버튼/등록 식별자는 타인에게 없음.
4. 일부 완료 뒤 변경: 완료분의 당시 캐릭터/기록 유지, 남은 참가 전체만 새 캐릭터로 표시되고 일정/후속 명령과 일치. 전체 완료 뒤 새 다음주는 명시 선택, 이미 참가한 다음주 자리는 유지.
5. 활동 미선택 후보: 기존 관리 저장/취소 후 원래 방/주차/변경 sheet 복귀·후보 재조회·명시 확정. 갱신/조회 실패 시 경고 보존·조회만 재시도, 중복/자동 참가 변경 없음.

## 확인된 개발 기준선

PC 포맷 후 Flutter3.41.6/Dart3.11.4/Java21·기존 설정/고정 의존성 복구와 사용자 dev 로컬 에뮬레이터 Google 로그인 인수를 마쳤다. 복구 당시 분석0/debug APK 빌드·인증 세션15PASS와 이전 기능 전체2817PASS는 서로 다른 검증 범위이며 이번에 다시 실행한 결과가 아니다. 공개 서명 식별표는 [Google 로그인 계약](../architecture/GOOGLE_LOGIN_CONTRACT.md#포맷-후-로컬-복구oauth-서명-식별-2026-11-07)을 따른다.
