# NEXT WORK — 신규 서버 설계 인계

## 최신 Git 통합 지시 (2026-10-13)

사용자 후속 승인으로 현재 문서 변경을 커밋하고 최신 origin/dev에 통합한 뒤 dev를 푸시한다. 아래 단계별 미커밋·통합 제외 기록은 당시 범위이며 이번 지시로 갱신된다. 신규 서버 분석·설계 13문서와 기존 자료 보관·출처 기록이 통합 대상이다. 기존 로컬 실험·백업과 앱 코드 변경은 제외한다. 문서 검증은 완료했으며 통합 후 다음 작업은 별도 백엔드 저장소의 요구사항 Issue·계약 설계다. 배포와 실제 데이터 변경은 수행하지 않는다.

> 기존 서비스 전용 항목은 [원문·출처 기록](../../legacy/firebase/extracted/docs/project/NEXT_WORK.md)으로 분리했다. 남은 제품/협업 문맥의 신규 서버 적용 여부는 별도 설계에서 판단한다.

## 현재 작업 — 기존 서비스 문서 레거시 분리 (2026-10-13)

사용자 지시로 기존 Firebase 전용 문서는 루트 legacy/firebase 아래 원래 docs 분류 경로로 이동한다. 제품/공용 지침/개발 이력 등 혼합 문서는 관련 절·문단·목록을 분리해 추출 문서에 원본 파일/절/행 범위를 기록한다. 일반 제품 정책·공용 협업 지침과 이번 신규 서버 설계 기록은 유지한다. backend-migration 13문서는 내용/위치 모두 제외·보존한다.

순서: 전용/혼합 분류와 참조 확인 → 파일 이동/관련 항목 추출 → 상대링크/문서 지도·지침 경로 갱신 → 출처·내용 보존/코드·설정 및 제외 문서 SHA·diff 검증. 기존 미커밋 결과/실험·백업 유지,앱/Rules/설정·운영 데이터/배포·커밋/push/merge 없음. 옛 운영 배포 절차를 신규 서버 작업의 자동 지시로 재사용하지 않는다. private 로컬 문서는 추적 제외 성격을 유지한다.

아래 사전 분석 단계의「기존 익명 Player 연결/복구·운영데이터 이관 실사」미결정 문구는 이번 사용자 정책으로 제외됐으며 현재 할 일로 재사용하지 않는다. 최신 결정과 설계안/남은 입력은09~12를 따른다.
