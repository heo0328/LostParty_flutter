### 파티 구성판 확정 방향

- 모바일은 1열 슬롯 Card, 넓은 화면은 가용 폭 기준 2열을 기본으로 한다. 고정 열이 많은 전통적인 DataTable은 긴 캐릭터명과 접근성 글자 크기에 취약하므로 사용하지 않는다.
- 점유 슬롯은 자리 번호, 파티장/공대장 배지, 캐릭터명, 직업, 전투력, 아이템 레벨과 역할을 표시한다.
- 빈 슬롯도 항상 렌더링해 정원과 실제 구성을 한눈에 확인할 수 있게 한다.
- 탈퇴·추방으로 빈자리가 생겨도 다른 멤버를 자동으로 당기지 않는다. 자리 이동은 명시적인 후속 명령으로 처리한다.
- 캐릭터 변경은 기존 슬롯을 유지한다. 향후 슬롯 조건은 membership이 아니라 별도 슬롯 요구조건으로 관리한다.

### 최종 후속 채팅 범위

- 모든 핵심 파티·슬롯·그룹 기능이 안정된 뒤 가장 마지막에 구현한다.
- 파티 상세에 진입한 현재 멤버만 최근 메시지 약 10개를 실시간으로 읽고 쓸 수 있다.
- 표시 내용은 캐릭터명 또는 표시 ID와 짧은 텍스트이며 이미지·파일·읽음 상태·푸시 알림은 초기 범위에서 제외한다.
- 메시지는 개별 문서로 저장하고 `createdAt desc`, `limit(10)`만 구독한다. 상세 화면 이탈 시 listener를 해제하며 목록·다른 탭에서는 읽지 않는다.
- 메시지 길이와 연속 전송을 제한하고 서버 timestamp, 멤버 권한 Rules, 파티 완료·해산 후 접근 정책을 구현 전에 확정한다.
