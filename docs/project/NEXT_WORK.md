## 다음 작업

신청자 목록의 가벼운 표시(2단계)를 최신 `dev`에서 별도 브랜치로 구현한다.

포함:

- 신청 Snapshot의 `itemLevel`·`combatPower`를 읽기 모델과 신청자 행 UI에 연결한다. 값이 없는 과거 신청은 미확인으로 두고 0으로 채우지 않는다.
- 신청 직업·역할과 로컬 시너지 카탈로그로 판별 가능한 주요 시너지(항상 채용·공통 효과)를 목록에 표시한다.
- 표시 시점은 신청 당시 Snapshot이다. 최신 세팅 조회나 신청 값 덮어쓰기는 하지 않는다.

제외:

- 특성 최소 요약 스키마와 모든 직업 빌드 판별
- 전체 Armory 원문 업로드, 상세 탭 지연 조회, 신규 Rules/인덱스
- 신청 중·완료 기록 필터, 시너지 슬롯 조건, 모집 만들기 입력 화면
