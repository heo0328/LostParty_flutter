Backend420e057 admit_bundle의 같은membership 과거Assignment.completed를 old.state!='left'로 거절하는 원인후보를 [Issue13 익명재현](https://github.com/heo0328/lostparty-backend/issues/13#issuecomment-6435522815)에 전달했다. Backend의 합성재현/확정원인·수정/검증/반영 회신 대기. 수정 전 재신청 성공으로 보고하지 않는다.

## 이전 파트 — 구현·자동검증 완료 / 기기 확인 유지

feature/raid-recruitment-scheduling 유지. 설계37 §37.84에 따라 시간 필터의 작은 글자 배율 예외, 내 계정 참가 중 체크의 개인 완료 후 탈퇴 진입, 편성 확정 거절을 미확인으로 보관한 잠금을 수정했다. 일반 앱 DI/화면에 연결했으며 직접 영향243개 시험·변경 분석0·포맷/diff검토를 마쳤다. 서버·자료·dev/main은 변경하지 않는다.

이전 파트 당시 기기 항목(이번 사용자 보고로 편성잠금·계정완료는 통과, 작은표시는 보완): (1) 기기에서 날짜 미선택 시간 필터 열기/취소/적용, (2) 기존 편성 미확인 요청의 ‘같은 요청 다시 확인’으로 서버 거절 확인 후 잠금 해제, 재편성 거절 시 입력 유지/오류 카드/다른 기능 사용 가능, (3) 내 계정 참가 중 체크→정확한 캐릭터/레이드 확인→개인 완료 후 탈퇴→계정에서 완료 표시. 확인창 취소는 변경하지 않는다. 기존 정상 상세 완료의 현황 목록 복귀는 보존했다. 추방·C/N개별관리는 이번 사용자 기기 보고로 통과했다.

이미 통과: 기본 출발 기한 처리, 수동 완료 해제, 저장 문구 기기 공유, 후보/가입·일정/조율·그래프·상세 완료 목록 복귀·승계·주차 독립. 재현 없는 복구 배너는 강제 기기 과제로 두지 않는다. 기존 잠긴 편성 요청은 임의 삭제/새키 교체/자동 전송하지 않고 같은 원요청에 대한 명시 재확인으로만 정리한다.
