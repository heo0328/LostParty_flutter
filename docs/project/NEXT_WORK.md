# NEXT WORK — 베타 기기 피드백 UI 마무리

## 현재 파트 — 필터 시계 한글화·비활성 선택 아이콘 가시성

사용자 기기 확인: 비5분 필터 입력·생성 선택/입력, 비5분 일정 제안·변경/확정 정상. 해산 시 build 중 setState 예외 재발 없음. 오류 확인창 가독성·과거 기록 보존/다른 캐릭터 재신청/가입도 통과했다. 같은 정상 시험을 반복하지 않는다.

이번 범위: 필터의 기본 시간 선택만 기존 공통 한글 picker로 연결한다. 필터의 숫자 입력 시작·분 원값·취소/회원·주차 수명과 명시 적용을 유지한다. 앱 선택 컨트롤(체크박스/라디오/스위치)은 비활성 아이콘이 식별되도록 테마 색만 조정하고 null 콜백/권한/선택값은 변경하지 않는다. 기능·화면 배치·통신은 변경하지 않는다.

검증 완료: 공통 picker·필터·테마 직접18개 PASS, 변경5 Dart 분석0·포맷/diff 검토. 이번 표시 수정의 기기 한글 문구/비활성 아이콘 가시성만 미확인이다. 전체 시험은 이 표시 변경에 불필요하다. 기존 작은 글자 배율/좁은 입력창 보완을 재사용한다. 완료 후 관련 문서·인수 결과를 한 UI 마무리 파트로 커밋/푸시하며 무관 dirty는 보존한다. dev/main 통합·서버/DB·자료 삭제는 없다.

차후 개선: 다음주 함께하기 개방 알럿에서도 build 중 setState 로그가 반복된다고 보고됐으나 사용자가 베타 우선으로 현재 수정에서 제외했다. 일정 제안 확인/수락 진입은 공대원 일정 전체 확인을 거쳐야 해 발견성이 낮다. 소켓 알림, 상세의 선택 주차 진행 일정 영역으로 진입 노출 등을 후보로 두고 개선 착수 시 더 나은 방식을 조사·UX 협의한 뒤 선택한다. 지금 배치를 바꾸지 않는다. 상세 추적은 설계37 §37.89.

기존 Native 실제 BetaSchedule.session_id 정밀도 판정 보완은 이번 표시 수정에 섞지 않는다. 사용자 정상 분 단위 제안 통과와 별개인 경계 정합성 후속이다.
