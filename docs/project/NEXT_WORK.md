## 남은 범위와 다음 행동

- 사용자가02의5개 기능 보드를 검토한다. 수정 요청은 기존 기능 보드/해당 섹션을 직접 갱신하고 사본을 늘리지 않는다.
- 작은 프로토타입 구조 시험은 중첩 화면의 navigate-to 생성/조회·임시 연결/flow 제거까지 확인했다. 실제 View의 클릭/스크롤은 미확인이다. 전체 앱 프로토타입은 별도 후속으로 유지한다.
- 인증 진행/확인 등 미대조 기존 자료는 회색 참조 섹션에 보존했다. 모든 실패/복구 알럿·장치 폭·긴 이름 조합의 전수 픽셀 대조를 완료로 주장하지 않는다. 해당 화면 재작업 시 실제 앱 상태를 추가 대조한다.

이번 범위는02 설명 보드 정리·정적 시각 검수·사용자 검토 제시까지다. Flutter/Backend·제품 UX·DB·전체 프로토타입·dev/main 통합·03 이관은 포함하지 않는다. 기존2,739PASS/분석0·사용자 그룹 인수는 유지하며 문서/디자인 변경으로 앱 시험을 반복하지 않는다.
