## 후속 과제 1 — 복구키를 통한 기존 사용자 복구

아직 구현하지 않는다. 재설치·기기 변경 후 새 익명 Auth UID를 복구키 검증을 거쳐 기존 Player에
연결하는 방향을 검토했다. 데이터 복사·병합이나 과거 소유권 되돌리기로 구현하지 않는다.
현재 유효한 원정대·그룹·레이드 관계를 다시 이용하는 것이 목표다.
복구키 발급/보관/검증/폐기, 기존 기기 접속, 새 임시 Player의 이미 생성된 데이터 처리,
캐시/구독 전환과 서버 권한을 설계에서 먼저 확정해야 한다. 신뢰된 검증 경로는 미선정이다.

## 후속 과제 2 — 소유권을 잃은 원정대의 기존 관계 처리

기존 승인 목표 유지: 새 인증자는 과거 사용자의 참가·그룹·완료 이력을 승계하지 않고 이용한다.
이전 사용자에게 남은 신청·활성방/완료방 참가·공대장 관계를 어떤 시점과 주체가 정리할지 설계한다.
동일 방에 같은 캐릭터가 이전·새 사용자로 중복 표시된 관찰을 이 과제에 포함한다.
진행 중 방에서 남은 참가자들이 소유권을 잃은 사람의 행동을 기다리지 않도록 해야 한다.
다른 원정대, 사용자 단위 정상 그룹 가입과 완료 이력을 일괄 삭제하지 않는다.
현재 완료 반복방 단건 정리만으로 모든 활성방/중복 가입 문제까지 해결됐다고 간주하지 않는다.

## 미확정 관찰과 통합 조건

- 그룹 반복방의 동일 직업 자리 교환 권한 오류: 탈퇴·재가입 후 성공, 일반 반복방에서는 성공.
  일시적 오류·데이터 불일치·Rules 경로 원인 모두 미확정. 사용자 지시로 수정하지 않음.
- 기존 반복방 자격 확인 버튼 오류: 13시 이후 재확인 결과 미보고. 원인을 주간키로 확정하지 않음.

- 일반/그룹방 생성·신청·수락 및 재인증 후 새 사용자 이용 사용자 통과.

- 실기기 테스트 목록은 문서에 새로 넣지 않고 채팅에서 제공한다.
