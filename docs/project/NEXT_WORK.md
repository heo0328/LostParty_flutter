보존한 사용자 통과: 여러 종류/C/N 단독·동시 생성·주차별 날짜시각, 메모 저장/직접입력/공대장 읽기, 승인/대기/철회/거절, 직업중복/완료 후보 제외, 참가후 검색 제외, 생성 화면 재진입. 현황 카드 이름은 사용자의 계정 혼동 정정이므로 기존 내 참가 캐릭터명을 유지하며 결함으로 남기지 않는다.

검증: 최종 모집 기능1183PASS, 변경12Dart 분석0·포맷/diffcheck/리뷰. 복구의 구형 기대revision 원요청/원ACK 확인·잘못된 revision 거절과 ASCII 전체/제어·이모지 제외·오류 구분을 추가했다. 이번 기기 수정 결과는 아직 재확인 전이다. 다른 기기 자동갱신(웹소켓)·BUG025·IF001·리디자인/개발자료 변환삭제·dev/main 통합은 제외한다.
