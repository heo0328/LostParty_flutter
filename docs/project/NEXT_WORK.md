## 다음 파트 — 검색 필터·일정 상태 표시 연결

이미 승인된 §37.63/65의 실제 출발 기준 날짜/시간대·조율 상태 필터와 기존 남은자리/참가인원 정렬 흐름을 대조해 일반 검색 화면에 연결한다. 착수 때 최신 Issue13/조회 계약·현 코드의 필터/페이지 처리와 기획 일치를 확인하고 포함/제외·데이터 갱신/권한·직접 회귀를 먼저 기록한다. 카드별 상세 요청·미정 생성/필터·화면 전면 리디자인을 추가하지 않는다. 실제 사용자 인수는 생성→가입→방내부→완료/해체→C/N의 분량으로 나누되 전체 영향은 보호한다.
