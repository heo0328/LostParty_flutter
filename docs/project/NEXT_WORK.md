## 현재 확인할 한 구간 — 내 계정 시간 설정

2026-10-20 사용자 수동 확인으로 **최초 등록·수정·동일 일자 추가 시간 등록·앱 재시작 후 동일 계정 데이터 불러오기**가 통과했다. 추가로 다른 디바이스 복원도 사용자 확인 통과이며, 와이파이 OFF/ON 후 통신 가능한 때 마지막 저장 데이터가 정상 기록되는 것으로 보인다는 관찰을 받았다. 아래 항목 중 확인된 흐름은 반복 확인 대상에서 제외한다. 실제 실행 Backend SHA는 별도 전달받지 않았으며 에이전트가 실서버/기기를 재시험한 결과는 아니다. [Issue13 결과 회신](https://github.com/heo0328/lostparty-backend/issues/13#issuecomment-6291576691)에 확인 범위를 기록했다.

1. 인증 원정대 회원의 내 계정에서 결과 영역과 계정카드 사이 접힌 시간카드가 보이며 기존 카드/왕관·주간·하단탭이 유지되는지 확인한다. 비로그인 전환시 회원 초안이 남지 않아야 한다.
2. 수~화 선택/해제·같은요일 +복수행/빨간− 삭제·시작/종료5분휠·다음날을 확인한다. 예: 금23:00~토03:30, 같은시각+다음날=24h. 0시간/24h초과는 저장되지 않고 신규행에 예시시간이 자동저장되지 않아야 한다.
3. 취소시 기존 저장값 유지/접힘, 저장성공시 접힘과 다시펼침의 값, 재시작/다른기기 복원은 사용자 확인 통과다. 로컬DB에새개인표영속저장은없다.
4. 통신실패시 초안유지·저장재시도를 확인한다. 결과불명은같은키/본문재전송, 충돌은최신값확인후사용자재저장이다. 저장값확인은기존실행요청의취소가아니며오래된완료/다른회원값을현재초안에끼워넣지않는다.

실기기 설치·조작은 사용자가 수행한다. 최초 등록·수정·동일 일자 추가·동일 계정 재시작 복원은 위 사용자 확인으로 갱신한다. 다른 회원 격리·익일/24h·취소·기기 시각과 최근 관리 복귀/결과 X는 미확인이다. 와이파이 전환 관찰만으로 완전 오프라인·결과불명 재시도·동시 수정 충돌의 세부 검증 통과를 단정하지 않는다. [추가 결과 회신](https://github.com/heo0328/lostparty-backend/issues/13#issuecomment-6291840658)에 기록했다. 진단로그는오류원인판별에필요할때만요청한다.
