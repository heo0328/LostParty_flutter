## B. 최상단 일반/그룹 선택과 실제 연결

다음 구현 지시 시 최신 main에서 전용 브랜치를 생성한다. A와 한 작업으로 묶지 않는다.

- §9.2의 단일 그룹 확정에 따라 최상단 모드와 가입 그룹 하나를 선택하는 드롭다운을 연결한다.
- 그룹 미가입/선택 없음/목록 로딩·실패/선택 후 탈퇴를 처리한다. 일반 모드에서는 그룹 선택을 숨기고 전송값에서도 제외한다.

- 그룹 전용/전체 공개·그룹 탈퇴 시 참가 자격 정책은 기존 단일 그룹 제품 계약을 보존한다.
- 실제 데이터·Rules 확장은 필요한 범위를 먼저 정리하고 독립 구현 단위로 진행한다. 전체 그룹 관리 기능과 묶지 않는다.
