# NEXT WORK — 레이드 모집·일정의 현재 실행 기준

## 직전 파트 — Penpot 승인 디자인 대조·검색 필터 연결 완료

76e0f378 이후 동일 모집 브랜치에서 Penpot03 실제 보드01/02/04/05/17의 PNG·속성을 확인하고 검색 필터 및 목록 표시를 연결했다. 흰 카드·보라 선택·작은 사각 버튼·2열 캐릭터, 신청 메모의 전체폭 저장문구 행과 별도 문구 관리 페이지를 반영했다. 상세 계약/근거는 설계37 §37.74, 검증 이력은 DEV_LOG에 둔다. Backend d95e3827 wire2를 사용하며 서버 변경은 없다.

일정 필터는 실제 선택 주차의 날짜/시간을 UTC 범위로 전환하고 상태 그룹을 서버 검색 조건에 전달한다. 편집 중 검색0·취소는 원조건 유지·적용 시 필요한 검색 최대1회, 즉시 정렬 토글/남은자리·숙련도 다중선택/그룹원 내부 레벨 정렬을 보존한다. 자동 검증1142PASS·변경10Dart 분석0·포맷/diff·320/390/720px 필터와 좁은 그룹 카드·메모/관리 렌더를 확인했다. 실제 기기/실회원 인수는 미실행이다.

## 다음 파트 준비

우선 Penpot03 일정08~15 등 이미 연결된 나머지 화면의 실제 디자인을 대조해 승인된 그래프/제안/응답 배치와 다른 부분을 확인한다. 이번 필터 파트로 전체 앱 디자인 일치 완료를 주장하지 않는다. 확인된 차이는 기존 승인 UX 복원 범위로 정리하고, 기능/조작 방식의 신규 변경이 필요할 때만 사용자와 협의한다. 별도 전면 리디자인·기능 확대는 하지 않는다.

전체 참가명령의 앱 재시작 영속 복구는 아래 유효 후속에 남아 있다. 실제 연결/디자인 확인과 복구 범위를 대조한 뒤 정상회원·사용자 기기의 생성→가입→방내부→완료해체→C/N 테스트를 소수 항목씩 진행한다. 서버 배포/DB/자료삭제·dev/main 통합은 현재 승인 범위가 아니다.
