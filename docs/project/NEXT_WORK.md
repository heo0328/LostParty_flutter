# NEXT WORK — 그룹 상세 통합 개편 기기 인수

## 현재 상태·범위

2026-10-31 사용자가 Penpot03의04~07 디자인을 확인·승인하고 Flutter 구현을 지시했다. docs/group-native-design 브랜치를 유지한다. Penpot03→02 이관은 개발·기기 확인 여부와 관계없이 사용자 별도 지시가 있을 때만 수행한다.

기존 API·명령·CAS·원요청 복구를 재사용해 상세에 정보/신청·초대/코드를 연결했다. 구현·자동 검증 완료이며 다음 행동은 이번 개편의 사용자 기기 인수다. 앱 Router의 기존 상세를 수정하며 초대·레이드·신청 금지 목적 페이지와 개인 요청 현황은 유지한다. Backend/DB·AWS/release·dev/main 통합·별도 기술 개선은 제외한다.

## 구현 내용·데이터 소유

1. 상세 ViewModel이 그룹원·요청·코드·관리 권한을 각각 조회하고 독립 로딩/실패/재조회 상태로 보관한다. 기존 회원/환경/observation 수명 가드를 유지하며 조회 실패를 빈 목록/코드 없음으로 만들지 않는다. 그룹원은 기존 rows 원본, 요청은 별도 목록, 코드는 기존 code 원본이다. 새로운 영속 캐시나 쓰기 API를 만들지 않는다.
2. 승인한 순서/390·320 반응형 배치를 연결한다. 이름은 현재 값 알럿, 이전은 현재 그룹원 선택 후 확인, 추방은 펼침에서만 노출한다. 서버 permissions·CAS로 명령하고 성공 뒤 권한/영역을 재조회한다.
3. 권한 변경·회원 전환·늦은 응답·한 영역 조회 실패·성공 후 조회 실패·중복 쓰기/취소를 직접 검증한다. 기존 그룹 명령/원ACK·가입/초대/공개코드·주차별 모집 경계를 회귀 보호한다. 포맷·diffcheck·직접 그룹 시험·분석을 실행하고 영향 범위에 따라 확대한다.
4. 코드/검증/문서를 같은 파트로 커밋·푸시한다. 기기 설치/조작은 사용자 담당이며 긴 이름·320/390 버튼·알럿·관리 후 권한/갱신을 안내한다. 이번 개편 기기 인수 전에는 전체 완료로 보고하지 않는다.

## 확정 배치·보호할 흐름

- 그룹 정보 카드 → 그룹장 신청/초대 관리 → 초대코드 카드 → 사용자 초대/그룹 레이드 → 신청 금지 인원 → 그룹원/펼침 → 하단 탈퇴/해산 순서.
- 그룹명/대표명 오른쪽 변경 아이콘. 이름 알럿은 현재 이름·1~20자/앞뒤 공백 제외·취소/저장. 대표는 기존 선택 흐름. 그룹장 이전은 확대 정보 카드 안 버튼→본인을 제외한 유효 그룹원 등록 대표명 선택→최종 확인. 즉시 이전·본인은 일반 멤버 유지·탈퇴 별도.
- 정상 빈 요청은 “새로운 그룹 가입 신청, 초대가 없습니다.” 한 줄. 요청 종류/대상/만료와 허용 승인·거절·취소는 인라인으로 표시. 조회 실패/로딩을 빈 결과로 합성하지 않는다. 일반 멤버 개인 요청 현황 유지.
- 코드 생성/복사/공개/재발급/폐기를 상세에 통합. 일반 멤버는 공개 코드만 조회/복사한다. 미발급·비공개·재발급 대기, 공개OFF와 폐기를 구분한다.
- 주요 두 버튼은 좌우16·간격12·높이44·1:1.320px에서는138×44씩 한 줄,390px에서는173×44씩 한 줄이다. 신청 금지 인원은 다음 행 보조 버튼·기존 페이지 이동.
- 추방은 그룹장이 타인 카드를 펼쳤을 때만 이름 오른쪽에 시각56×32·터치 최소48×48로 계획한다. 펼치기와 분리하고 대상 이름 확인 후 실행한다. 해산은 최하단·기존 조건/차단 사유/레이드 확인 유지. 별도 정보/코드/요청 관리 페이지 진입을 실제 상세에서 제거했다.

## 보존·완료 조건

기존 그룹1차 인수/주차별 독립 정책·레이드 참가/신청/일정/예약/완료·원요청 복구·탭 보호를 보존한다. 기존 원인 미확정 GET500 조사나 서버 재시험을 이번 배치의 선행 조건으로 추가하지 않는다. 실제 앱 연결·자동 경계 검증·사용자 기기 인수를 구분해 기록한다. 구현·실제 앱 연결·자동 검증 완료, 이번 개편의 사용자 기기 인수 대기다.


## 사용자 기기 확인 — 이번 개편만

1. 그룹장 상세에서 이름/대표 아이콘·그룹장 이전이 정보 카드 안에 있고, 초대/레이드가 같은 행인지 확인한다. 긴 이름·일반 화면/폴드 외부·키보드가 열린 이름 알럿의 잘림과 추방 크기는 사용자 실제 화면에서 확인한다.
2. 신청/초대를 상세에서 처리하고 코드의 공개/복사/생성·재발급·폐기를 확인한다. 일반 멤버에서는 편집/신청 관리/이전/추방이 숨고 공개 코드와 개인 요청 현황은 기존 권한을 따른다.
3. 펼친 타인에게만 추방 버튼이 있으며 펼치기와 별도로 눌리는지, 이전 대상 선택→최종 확인→일반 멤버 화면 갱신을 확인한다. 확인 취소는 쓰기가 없다. 하단 탈퇴/해산 조건·차단 레이드 경로도 확인한다.

기존 주차별 레이드 인수 전체를 다시 요구하지 않는다. Penpot03은 사용자 별도 이관 지시까지 그대로 유지한다. dev/main 통합은 이번 파트에서 하지 않는다.

## 최종 자동 검증
