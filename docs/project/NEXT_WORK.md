자동조율 안내 계약: 기존 beta 상세/plan GET에만 include_coordination_wait=true를 명시해 beta_schedule.coordination_wait를 받는 안을 수용했다. 생략/false 응답과 기존 reader 조합·기존일정/기록의 null은 유지한다. waiting_members(양수)/no_earlier_candidate/pending/unavailable/not_applicable(각null)을 기존 카드 한 줄로 표시하며 문구는 설계37 §37.80에 고정했다. 조회 실패/누락을 후보 없음으로 바꾸지 않고 실제 전원·같은 snapshot을 쓴다. 새 API/반복조회·폴링/웹소켓·레이아웃 변경은 없다. [6412692643](https://github.com/heo0328/lostparty-backend/issues/13#issuecomment-6412692643) 회신으로 소비 확인은 끝났으며 Backend 실행계약/구현 인계 뒤 native에 연결한다.

보존한 사용자 통과: 여러 종류/C/N 단독·동시 생성·주차별 날짜시각, 메모 저장/직접입력/공대장 읽기, 승인/대기/철회/거절, 직업중복/완료 후보 제외, 참가후 검색 제외, 생성 화면 재진입. 현황 카드 이름은 사용자의 계정 혼동 정정이므로 기존 내 참가 캐릭터명을 유지하며 결함으로 남기지 않는다.

검증: 최종 모집 기능1183PASS, 변경12Dart 분석0·포맷/diffcheck/리뷰. 복구의 구형 기대revision 원요청/원ACK 확인·잘못된 revision 거절과 ASCII 전체/제어·이모지 제외·오류 구분을 추가했다. 이번 기기 수정 결과는 아직 재확인 전이다. 다른 기기 자동갱신(웹소켓)·BUG025·IF001·리디자인/개발자료 변환삭제·dev/main 통합은 제외한다.
