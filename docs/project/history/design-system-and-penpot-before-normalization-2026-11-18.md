## 출처와 정리 기준

- 정비 전 문서: `docs/design/LOSTPARTY_DESIGN_SYSTEM_V1_REQUEST.md`, Git `91d0fe9d` 시점. 원문 전체는 해당 커밋의 파일 이력으로 확인할 수 있다.
- Firebase 전용 발췌는 [기존 레거시 원문](../../../legacy/firebase/extracted/docs/design/LOSTPARTY_DESIGN_SYSTEM_V1_REQUEST.md)을 유지한다.
- 확정 색/간격/곡률·공통 컨트롤·반응형/보드 운영·숫자 표시 등 유효 규칙은 현재 지침으로 통합했다. 이 문서에 중복 복제하지 않는다.
- 최초 목적·중복된 컴포넌트 설명·완료된 Theme/토큰 구현 순서·Codex 구현 요청은 현재 지침에서 제거했다. 과거 요청을 현재 코드 수정 승인으로 재사용하지 않는다.

## 초기 디자인 제안에서 남기는 판단 근거

- 최초 방향은 Soft Lavender Gaming Utility였다. 게임 UI의 어두운 배경·금색 장식·판타지 스타일을 직접 모방하지 않고 밝은 유틸리티 앱을 지향했다.
- Neutral 약75% / Lavender·Purple 약15% / 상태색 약10%는 당시 분위기를 설명한 비율이며 현재 화면에 강제할 픽셀·면적 계약이 아니다.
- 모집 대표 Card를 첫 검증 대상으로 선정했다. 당시 우선순위 제안은 제목·모집 상태 → 레이드/난이도/관문·시간·인원 → 아이템레벨/숙련도 등 metadata였다. 현재 모집 배치는 실제 코드와 후속 승인 결과가 우선한다.
- Dealer의 muted coral/red·Support의 muted mint/teal은 초기 검토 후보였다. 확정된 역할색으로 사용하지 않는다.
- 텍스트 동작에 TextButton을 허용하던 초기 후보는 2026-11-15의 배경/테두리 버튼 기준으로 대체됐다. 재현 시 실제 구현 예외는 대응표에 기록한다.
- Light Theme부터 적용하고 Dark Theme은 후속으로 두는 방향, 시스템 폰트·작은 토큰 구조 유지 등 유효 기준은 현재 지침에 통합했다.

## 내 계정 배치·시안 준비 당시 기록

아래는 정비 전 문서의 해당 절 발췌다. API 토큰 도구·미적용 표기·옛 보드 ID는 당시 상태이며 현재 사용 지시가 아니다. 이후 실제 구현과 현재 MCP 조회 결과가 우선한다.

### 내 계정 화면 배치 확정 (2026-10-14)

사용자가 현재 디자인 유지와 dev 통합을 승인했다. 화면은 메인 계정 등록 현황 → 부계정 등록 현황 → 계정 도구 순서다. 캐릭터 정보·레이드 현황을 먼저 표시하고 부계정 추가는 부계정 제목 옆에 둔다. 서버 등록 안내·API 토큰/인증·캐릭터 조회 입력과 조회 프로필은 하단 계정 도구에 둔다. 계정 없는 상태는 영역별로 안내하며 기존 카드·대표/표시 순서·관리/수정/삭제/갱신 기능을 유지한다. 이 배치는 서버 UUID와 로컬 계정 데이터를 통합하거나 신규 등록 API를 연결하는 변경이 아니다. 다음 등록 기능에서도 이 정보 순서를 유지한다.

### 내 계정 리메이크 시안 준비 (2026-11-13, 미적용)

현재 위 배치는 구현 기준이며 새 시안의 확정 제품 범위는 [내 계정 준비 항목](../../product/DETAIL_IMPROVEMENTS.md#my-account-ui-remake)을 따른다. 사용자가 현재 앱을 크게 바꾸지 않는 C방향의 곡선·영역 구분을 선택했다. 캐릭터/레이드 표시 개수 제거·사용 전원표시·시간표·웹런치 정책은 신규 확정 의도이며 기존 표시개수 보존 문구보다 우선한다. 구현 반영/실기기 확인 완료라는 의미는 아니다.
