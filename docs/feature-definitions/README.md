# LOSTPARTY 기능 정의 문서

> 기존 서비스 전용 항목은 [원문·출처 기록](../../legacy/firebase/extracted/docs/feature-definitions/README.md)으로 분리했다. 남은 제품/협업 문맥의 신규 서버 적용 여부는 별도 설계에서 판단한다.


- 인증, 레이드, 그룹처럼 여러 기능 영역을 하나의 사용자 흐름으로 연결한 문서
- 화면 분기, 사용자 행동, 주요 식별자와 데이터 책임을 함께 설명하는 문서
- 외부 도식화나 제품 흐름 검토의 기준이 되는 상위 문서
