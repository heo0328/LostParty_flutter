## 이번 작업 그룹의 목표

모집 상세에서 내 계정 캐릭터와 역할 세팅을 선택해 신청하고 신청 상태를 확인하는 UI를 구현한다.

## 포함 범위

- 현재 로컬 사용자의 계정 캐릭터 선택
- 저장된 딜러·서포터 세팅에 따른 신청 가능 역할 표시
- 입장 레벨, 최소 전투력, 역할 자리와 동일 딜러 직업 조건 안내
- 신청 명령 연결과 pending 상태 표시
- 신청자 본인의 철회 UI
- 신청 성공·실패 및 목록/상세 자동 반영
- Widget·전체 테스트와 Galaxy Z Fold6 검증

## 선행 결정

- 정족수 2명 이상 정책은 최초 파티원이 파티장 1명뿐일 때 첫 가입을 승인할 수 없다.
- 신청 UI 연결 전에 `초기 가입은 파티장 승인`, `정족수 충족 전 파티장 단독 승인`, `초기 멤버 직접 추가` 중 제품 규칙을 확정해야 한다.

## 제외 범위

- 파티장/파티원의 승인·거절·투표 조작 화면
- 사용자 전환용 제품 UI
- 계정 그룹과 Firebase

4. 신청·철회 명령과 상태 표시 연결
5. Widget·전체 테스트와 실기기 검증
6. 문서화, 기능 브랜치 푸시 및 `main` 병합·푸시
