3. 사용자가 선택한 경우에만 디바이스 로컬에 최근 레이드 조건을 기억하고 다음 생성·지원에 재사용

## 후속 모집 제목 기본값 규칙

- 사용자가 모집 제목을 입력하지 않았을 때만 자동 제목을 적용한다.
- 조합 순서는 `난이도별 게임 내 별칭 → 숙련도 → 최소 전투력 → 모집`이다.
- 게임 내 별칭은 레이드 카탈로그 난이도의 `displayAlias`를 사용한다.
- 설정되지 않은 숙련도와 최소 전투력은 제목에서 생략한다.
- 최소 전투력은 천 단위 쉼표를 적용하고 별도의 `이상` 문구 없이 숫자만 표시한다.
- 예: 세르카 하드, 추가 조건 없음 → `하르카 모집`
- 예: 세르카 나이트메어, 반숙, 최소 전투력 5,000 → `나르카 반숙 5,000 모집`
