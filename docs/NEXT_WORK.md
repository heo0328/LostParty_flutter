## 신규 파티 참가 기준

- 상세 기준은 `PARTY_PARTICIPATION_RULES.md`를 따른다.
- 본계정과 부계정은 모두 한 사용자의 소유이며 같은 파티에 둘 이상의 자리로 참가할 수 없다.
- 파티장은 자기 모집에 다른 소유 캐릭터로 지원할 수 없다.
- 모집 생성은 해당 캐릭터의 확정 참가이며 같은 캐릭터로 동일 레이드의 다른 난이도 모집을 중복 생성·가입할 수 없다.
- pending은 자리를 예약하지 않으므로 같은 캐릭터·레이드의 복수 승인형 신청을 허용한다.
- 최초 승인·즉시 가입·모집 생성이 확정 점유권을 얻고 다른 충돌 pending은 자동 종료한다.
- 같은 사용자는 본계정과 부계정을 합쳐 동시간대 둘 이상의 파티에 확정 참가할 수 없다.
- 캐릭터 변경 시 충돌 pending 철회 후 변경을 먼저 구현하고, 확정 파티 간 이동·스왑은 Firebase 트랜잭션 단계에서 별도 구현한다.

## 주간 레이드 완료 기준

- 레이드 주차는 한국 시간 기준 매주 수요일 오전 6시에 변경된다.
- 귀속 단위는 `캐릭터 + raidId + resetWeekKey`이며 난이도는 공유한다.
- 같은 캐릭터가 한 난이도를 완료하면 그 주차에는 같은 레이드의 다른 난이도에도 신청·가입·교체할 수 없다.
- 현재 승인된 파티원은 누구나 파티 완료를 선언할 수 있고 한 명의 선언으로 파티를 완료 처리한다.
- 완료 순간의 승인된 파티원 캐릭터 전체를 해당 레이드의 주간 완료로 기록한다.
- 완료된 파티에서는 신청 승인, 캐릭터 교체 및 완료 중복 선언을 허용하지 않는다.
- 초기 버전은 별도 동의·투표·개인 확인 없이 단일 파티원 선언을 최종 결과로 사용한다.

## 파티 내 캐릭터 교체 기준

- 파티장 포함 현재 승인된 파티원은 완료 전까지 자기 캐릭터만 교체할 수 있다.
- 가입 때 승인된 역할과 파티 자리는 유지하며 역할 변경은 캐릭터 교체 범위에 포함하지 않는다.
- 새 캐릭터는 본인 계정 소유, 해당 역할 세팅, 카탈로그 입장 레벨, 주간 미완료 및 모집 추가 조건을 모두 충족해야 한다.
- 딜러 교체 시 동일 파티의 동일 딜러 직업 제한을 포함해 전체 파티 구성을 다시 검증한다.
- 모든 조건을 만족하면 추가 승인 없이 교체하고, 하나라도 실패하면 기존 캐릭터와 파티 구성을 유지한다.
- 캐릭터 교체는 승인·파티 구성 UI 직후, 파티 완료와 `내 파티` 화면보다 먼저 구현한다.

- 파티장이 설정하는 최소 전투력, 클리어 경험 및 최대 진행 시간은 선택 조건이다.
- 선택 조건을 입력하지 않으면 해당 항목은 제한 없음으로 저장·표시·검증한다.

## `내 파티` 화면 기준

- 하단 탐색은 `내 계정 / 파티 모집 / 내 파티`로 구성한다.
- `내 파티`는 현재 사용자를 기준으로 `참여 중 / 내가 만든 파티 / 신청 중` 상태를 구분해 조회한다.
- `신청 중`은 아직 가입이 확정되지 않은 pending 신청이므로 참여 중인 파티와 섞지 않는다.
- 내가 만든 파티는 파티장 관리 화면으로 연결하고, 참여 중인 파티는 현재 파티 구성 상세로 연결한다.
- 신청 중인 파티는 신청 상태 확인과 철회 동작을 제공한다.
- 동일한 모집이 두 조건에 해당할 수 있으므로 하나의 Aggregate를 공유하고 화면에서는 상태·소유자 기준으로 분류한다.
- 로컬 Repository의 조회 계약과 상태 갱신을 먼저 검증하고 Firebase에서는 같은 화면 계약의 구현체만 교체한다.
