## 이번 작업 그룹의 목표

게임 카탈로그의 아이덴티티 및 아크패시브 특수 스킬 기준정보를 보석 대상 스킬 분류에 연결한다.

`ArmorySkills`에 없는 정상적인 특수 스킬을 `unknown`으로 잘못 분류하는 경우를 줄이되, 실제 장착 스킬과 정적 기준정보는 합치지 않는다.

---

## 결정된 설계 원칙

- `ArmorySkills`는 실제 장착 일반/각성 스킬 데이터로 유지한다.
- 카탈로그 특수 스킬은 별도 기준정보로 참조하며 API 스킬 목록에 삽입하지 않는다.
- 보석 대상 이름이 장착 스킬과 일치하면 `normal`로 분류한다.
- 현재 직업 카탈로그의 아이덴티티 또는 아크패시브 스킬과 일치하면 `passiveOrIdentity`로 분류한다.
- API 아이콘 판정은 카탈로그 판정의 보조 수단으로 유지한다.
- 어느 근거에도 일치하지 않을 때만 `unknown` 경고를 생성한다.
- 미지원 직업과 카탈로그 로딩 실패가 기존 스냅샷 분석 전체를 막지 않도록 현재 오류 경계를 유지한다.

---

## 구현 범위

### 분석기

- 현재 캐릭터 직업에 해당하는 카탈로그 특수 스킬 이름 조회
- 보석 대상 분류에 장착 스킬, 카탈로그 특수 스킬 및 아이콘 근거 적용
- 분류 우선순위와 `unknown` 경고 조건 명확화

### 카탈로그

- 기존 바드 최소 카탈로그의 아이덴티티 및 아크패시브 스킬로 흐름 검증
- 구조 검증에 필요한 경우에만 최소 필드 또는 조회 도우미 보완
- 다른 직업 데이터의 대량 수기 입력은 하지 않음

### 테스트

- `ArmorySkills`에 없는 바드 카탈로그 특수 스킬을 `passiveOrIdentity`로 분류
- 일반 장착 스킬은 계속 `normal`로 분류
- 카탈로그와 아이콘 근거가 없는 대상만 `unknown` 경고 생성
- 미지원 직업 및 계열 감지 실패에서도 기존 분석 결과 유지
- 저장된 원본 JSON 재분석 회귀 방지
