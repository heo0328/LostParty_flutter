## 이번 작업 그룹의 목표

실제 Lost Ark API 응답을 근거로 발키리 최소 카탈로그를 추가하고, 서포터 세팅의 `신앙 스킬` 복합 보석 대상을 공통 분석기로 정상 분류한다.

---

## 설계 원칙

- 직업별 묶음 스킬은 분석 코드가 아니라 버전 관리 JSON 카탈로그에 입력한다.
- API 직업명, 깨달음 1티어 노드, 특수 스킬 및 보석 대상 표시명은 실제 응답으로 확인한다.
- 실제 응답이나 신뢰할 수 있는 인게임 근거 없이 명칭과 관계를 추측하지 않는다.
- 직업별 fixture를 확보해 카탈로그 감지와 보석 분류를 회귀 테스트한다.
- 한 직업 데이터 추가 때문에 공통 분석기에 발키리 전용 분기를 만들지 않는다.
- 전체 직업을 한 번에 조사하지 않고 실제 사용·오류 발견 순서로 점진 확장한다.

---

## 구현 범위

### 입력 근거

- 발키리 서포터 종합 상세 API 응답 또는 익명화 fixture 확보
- API의 정확한 직업명, 깨달음 계열, 특수 스킬 및 `신앙 스킬` 보석 대상 확인
- 민감한 토큰과 불필요한 개인 식별 정보는 fixture 및 문서에 기록하지 않음

### 카탈로그

- 발키리 최소 직업 정의
- 확인된 서포터 계열과 역할
- 확인된 아이덴티티/아크패시브 특수 스킬
- `신앙 스킬` 복합 보석 대상과 관련 특수 스킬 ID 관계

### 테스트

- 발키리 직업 및 서포터 계열 감지
- `신앙 스킬`을 `passiveOrIdentity`로 분류
- 정상 대상에 `unknown` 경고가 생성되지 않음
- 바드 세레나데 분류 회귀 방지
- 미확인 대상 경고 유지
