# LOSTPARTY 2.3.0 업데이트 안내

내 계정 화면을 새롭게 정리하고, 개인 시간표와 캐릭터 관리의 편의성을 개선했습니다.

## 내 계정 화면 개선

- 휴대폰·펼친 폴드·웹의 화면 크기에 맞춰 카드와 영역을 배치합니다.
- 글자 크기와 버튼의 터치 영역을 개선했습니다.
- 넓은 웹에서도 화면이 지나치게 늘어나지 않도록 본문 폭과 정렬을 조정했습니다.
- 계정 도구를 버튼 형태로 정리하고, 로그인·로그아웃 버튼을 상단에 배치했습니다.
- 자동 갱신이 완료되면 결과 창이 접힙니다. ‘자동 갱신 결과 보기’로 다시 확인할 수 있습니다.

## 캐릭터 관리 개선

- 사용하도록 활성화한 캐릭터는 모두 표시합니다. 별도의 표시 개수 설정은 제거했습니다.
- 캐릭터 사용 여부·순서·대표 캐릭터 변경을 별도 저장 버튼 없이 바로 저장합니다.
- 순서 변경 카드 전체를 잡아 드래그할 수 있습니다.
- 대표 캐릭터는 메인 원정대에서 선택합니다.
- 캐릭터 관리 후 돌아오면 서버에 저장된 변경 내용을 다시 불러옵니다.

## 주간 레이드·개인 시간표

- 표시할 주간 레이드를 개수 대신 종류별로 선택합니다.
- 참가 중인 레이드는 난이도와 참가 상태를 함께 표시합니다.
- 주간 진행 가능 시간과 참가한 레이드의 예약 시간을 그래프로 확인할 수 있습니다.
- 예약을 선택하면 상세 안내와 해당 모집으로 이동하는 버튼을 제공합니다.

## 모집·웹 이용 개선

- 모집 생성 화면의 기본 정보와 출발 일정 배치를 정리했습니다.
- 레이드 추가·진행시간 설정을 바로 표시하고, 날짜를 바꿔도 입력한 시간은 유지합니다.
- 연결 그룹 선택을 입력 영역에 겹쳐 표시하는 메뉴로 변경했습니다.
- 모집 상세의 이번주·다음주 탭 표시와 모집 기록 조회 오류를 수정했습니다.
- 웹에서는 시작 화면의 인위적인 대기 시간을 없앴습니다. Android 앱의 시작 화면은 유지합니다.

## 이용 안내

- 웹 접속 주소: https://lostparty.duckdns.org/
- 기존 Android 2.1.0·2.2.0 사용자는 새 APK를 기존 앱 위에 설치해 업데이트할 수 있습니다.
- 웹과 앱은 같은 Google 계정의 서버 자료를 사용합니다. 기기에만 저장한 자료는 자동으로 공유되지 않습니다.

## 테스트 버전 안내

현재는 테스트 중인 버전입니다. 테스트와 서비스 개선 과정에서 저장된 자료가 부득이하게 초기화될 수 있으니 이용에 참고해 주세요.

문제가 발생하면 화면·수행한 동작·발생 시간·표시된 오류를 알려주세요. 비밀번호·API 키·토큰은 보내지 마세요.
