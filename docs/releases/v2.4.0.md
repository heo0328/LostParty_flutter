# LOSTPARTY 업데이트 안내

별도의 로스트아크 API 키 등록 없이 캐릭터 정보를 불러올 수 있도록 개선하고, 원정대 갱신과 모집 이용 흐름을 정리했습니다.

**업데이트 및 자료 초기화 안내**

이번 업데이트에서는 기존 회원·원정대·그룹·모집 등 서버에 저장된 모든 이용 자료가 초기화됩니다. Android 앱은 2.4.0으로 업데이트하고, 다시 로그인한 뒤 원정대를 등록해 주세요.

**API 키 없이 이용**

- 개인 API 키를 발급받거나 입력할 필요가 없습니다.
- 캐릭터 정보 조회와 갱신은 LOSTPARTY 서버에서 처리합니다.

**로그인 전에도 둘러보기**

- 로그인하지 않아도 모집 목록·상세, 모집 필터와 그룹 검색을 이용할 수 있습니다.
- 내 계정 화면에서는 예시 데이터로 주요 기능을 살펴볼 수 있습니다.
- 개인 데이터 관리, 모집·그룹 생성과 참가 등 로그인이 필요한 기능은 사용 시 로그인 안내를 제공합니다.

**원정대 갱신 개선**

- 원정대 인증에 성공하면 해당 원정대 정보를 자동으로 한 번 갱신합니다.
- 각 원정대에서 사용하도록 선택한 캐릭터만 수동으로 전체 갱신할 수 있습니다.
- 앱 실행 시에는 사용 선택 캐릭터와 새로 발견되거나 처음 아이템 레벨 1700에 도달한 캐릭터를 갱신합니다. 발견한 캐릭터를 자동으로 사용 등록하지는 않습니다.
- 갱신 진행 상황과 결과를 공통 카드에서 확인할 수 있습니다.
- 실패한 캐릭터의 이름과 사유를 확인하고, 실패한 항목만 다시 시도할 수 있습니다.
- 결과 카드를 닫았다가 다시 열어도 추가 갱신은 발생하지 않습니다.

**시간 설정·상태 표시 개선**

- 레이드 진행 가능 시간에 공통 시계 입력 화면을 적용했습니다.
- 기존 5분 단위 제한을 해제해 1분 단위로 설정할 수 있습니다.
- 캐릭터 카드의 ‘확인 필요’는 파랑 계열, 명확한 세팅 오류는 빨강 계열로 구분합니다.

**오류 수정**

- 도화가 캐릭터의 정보 갱신이 실패하던 문제를 수정했습니다.
- 모집 상세 정보가 표시되지 않거나, 그룹에서 모집 상세로 이동한 뒤 다른 모집을 선택하면 레이아웃 오류가 발생하던 문제를 수정했습니다.
- 비로그인 모집 조회 오류와 그룹 화면 버튼 간격을 개선했습니다.
- 모집 목록과 레이드 현황 조회 오류를 수정했습니다.

현재는 테스트 버전입니다. 문제가 발생하면 발생 화면과 수행한 동작, 발생 시간, 표시된 오류를 알려주세요. 비밀번호·API 키·토큰은 보내지 마세요.
