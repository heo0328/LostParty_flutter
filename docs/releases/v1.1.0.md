    - ‘다음 주도 함께하기’ 모집이 주차 변경 후 모집 목록에 정상 표시되지 않던 문제를 수정했습니다.
3. 8인 모집의 참가 캐릭터 변경 시 자동 자리 배정 수정
    - 현재 파티에서 동일 직업 제한에 걸리더라도 다른 파티에 유효한 자리가 있으면, 자리를 이동해 캐릭터를 변경할 수 있도록 수정했습니다.
