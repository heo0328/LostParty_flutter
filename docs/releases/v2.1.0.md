# LOSTPARTY 2.1.0 — 웹 지원·사전 테스트

이번 버전은 정식 베타 전 사전 테스트 버전입니다. 알려진 미확인 항목은 테스트 결과에 따라 보완합니다.

## 사용 방법

- 웹: https://lostparty.duckdns.org/
- Android: 이 Release에 첨부된 APK를 다운로드해 설치합니다.
- 웹과 앱에서 같은 Google 계정으로 로그인하면 같은 서버의 회원·모집 자료를 사용합니다. 브라우저와 앱의 로컬 전용 자료는 자동 공유되지 않습니다.

## 기존 Android 사용자 필독

이번 버전부터 Android 서명키가 변경됩니다. 기존 APK 위에 업데이트 설치할 수 없으므로 다음 순서로 진행하세요.

1. 기존 앱의 저장·전송 대기 작업을 확인하고 필요한 로컬 전용 자료를 별도로 보관하세요.
2. 기존 LOSTPARTY 앱을 삭제한 뒤 새 APK를 설치하세요.
3. 기존과 동일한 Google 계정으로 로그인하세요.

서버에 저장된 기존 회원·자료는 유지합니다. 앱 삭제 시 기기의 로컬 전용 자료와 미전송 작업은 사라질 수 있습니다. 데이터 복구를 위해 기존 서버 자료를 초기화하지 않습니다.

## 주요 변경

- 웹 실행과 브라우저 로컬 저장, Google 공식 버튼을 통한 로그인 연결.
- 묶음 레이드 전체·부분 선택 완료 및 참가 상태 복구 안내 보완.
- 누락 캐릭터 안내와 계정 복구, 조회 실패 시 재시도 안내 보완.

## 테스트 안내

- 실제 사용할 수 있는 주소이며, 주소를 아는 다른 사람의 접속을 제한하지 않습니다.
- 이번 테스트가 정식 베타 시작을 뜻하지는 않습니다. 정식 베타 시작 전 자료 초기화 시점은 별도로 안내합니다.
- 문제를 알려주실 때 발생 화면·동작·시간·표시 오류를 전달해 주세요. 토큰·API 키·비밀번호·전체 네트워크 기록은 보내지 마세요.
