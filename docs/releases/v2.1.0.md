# LOSTPARTY 2.1.0 업데이트 안내

웹 지원과 레이드 완료·복구 안내를 추가한 테스트 버전입니다.

## 주요 변경

- **웹 지원:** 앱 설치 없이 브라우저에서도 Google 로그인과 레이드 모집 기능을 사용할 수 있도록 준비했습니다. 웹과 앱은 같은 Google 계정의 서버 자료를 함께 사용합니다.
- **묶음 레이드 완료:** 묶음 레이드에서 전체 또는 일부 레이드를 선택해 완료할 수 있습니다.
- **오류·복구 안내 개선:** 누락 캐릭터와 처리 결과를 확인하지 못한 요청, 조회 실패 상황의 안내와 재시도 흐름을 보완했습니다.

## 기존 앱 사용자는 삭제 후 재설치해 주세요

이번 버전은 Android 앱 서명키 변경으로 기존 앱 위에 업데이트 설치할 수 없습니다.

1. 기존 LOSTPARTY 앱을 삭제한 뒤 이 페이지의 새 APK를 설치해 주세요.
2. 기존과 동일한 Google 계정으로 로그인해 주세요.

서버에 저장된 회원·자료는 유지됩니다. 다만 앱 삭제 시 기기에만 저장된 자료와 전송되지 않은 작업은 사라질 수 있습니다.

## 서버·웹 이용 안내

- 웹 접속 주소: https://lostparty.duckdns.org/
- 웹은 별도 설치가 필요하지 않으며, 주소를 아는 누구나 접속할 수 있습니다.
- 웹과 앱의 로컬 전용 자료는 자동으로 공유되지 않습니다.

## 테스트 버전 안내

현재는 테스트 중인 버전입니다. 테스트와 서비스 개선 과정에서 현재 버전에 저장된 자료가 부득이하게 초기화될 수 있으니 이용에 참고해 주세요.

문제가 발생하면 화면·수행한 동작·발생 시간·표시된 오류를 알려주세요. 비밀번호·API 키·토큰은 보내지 마세요.
