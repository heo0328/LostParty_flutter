# LOSTPARTY 2.2.0 업데이트 안내

레이드 모집을 찾고 조건을 고르는 화면을 새롭게 정리했습니다. 휴대폰·펼친 폴드·웹에서 화면 크기에 맞춰 모집을 탐색할 수 있습니다.

## 모집 검색·필터 개선

- 전체·일반·그룹 분류와 참가인원 정렬을 선택하면 바로 검색 결과에 반영됩니다.
- 상세 필터에서 레이드·난이도·숙련도·날짜·시간 등의 조건을 고른 뒤 적용할 수 있습니다. 편집 중에는 기존 검색 결과가 유지됩니다.
- 목록에 초기화 버튼을 추가했습니다. 현재 주차·분류·정렬을 유지하면서 상세 조건을 초기화할 수 있습니다.
- 필터 항목의 구획과 버튼을 정리하고, 연결 그룹에서 그룹원·캐릭터 조건을 선택할 수 있도록 모았습니다.
- 전체 검색 개수를 표시하며, 목록을 내려 다음 모집을 이어서 볼 수 있습니다. 최근 검색 결과를 잠시 재사용해 같은 조건의 반복 조회를 줄였습니다.

## 폴드·웹 화면 개선

- 펼친 폴드와 넓은 웹에서는 모집 목록과 선택한 상세를 나란히 볼 수 있습니다.
- 충분히 넓은 화면에서는 필터·목록·상세를 함께 표시합니다.
- 가로로 사용해 화면 높이가 낮아진 경우에도 전체 화면 필터에서 조건과 적용 버튼까지 스크롤할 수 있도록 개선했습니다.

## 이용 안내

- 웹 접속 주소는 https://lostparty.duckdns.org/ 입니다.
- Android 2.1.0 사용자는 기존 앱 위에 새 APK를 설치해 업데이트할 수 있습니다.
- 웹과 앱은 같은 Google 계정의 서버 자료를 사용합니다. 기기에만 저장한 자료는 자동으로 공유되지 않습니다.

## 테스트 버전 안내

현재는 테스트 중인 버전입니다. 테스트와 서비스 개선 과정에서 현재 버전에 저장된 자료가 부득이하게 초기화될 수 있으니 이용에 참고해 주세요.

문제가 발생하면 화면·수행한 동작·발생 시간·표시된 오류를 알려주세요. 비밀번호·API 키·토큰은 보내지 마세요.
