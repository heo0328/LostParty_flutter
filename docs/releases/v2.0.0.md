## LOSTPARTY 2.0.0 업데이트 안내

앱 시작 시 자동 갱신 속도를 개선하고, 그룹 초대와 활동 캐릭터 설정의 불편을 수정했습니다.

- **초기 로딩 개선**  
  원정대·캐릭터 정보의 조회와 저장 처리를 개선해 자동 갱신 대기 시간을 줄였습니다.

- **그룹 초대 안내 개선**  
  앱 회원이 아닌 캐릭터, 본인, 이미 같은 그룹에 가입한 사용자를 검색하거나 초대할 때 이유를 명확히 안내합니다. 일부 초대 실패에서 불필요한 새로고침 안내가 나타나던 문제를 수정했습니다.

- **활동 캐릭터 해제 처리 수정**  
  앱 사용 선택을 해제해도 이미 참가한 레이드는 정상적으로 이용할 수 있도록 수정했습니다. 해제한 캐릭터는 신규 모집·참가·캐릭터 변경 후보와 그룹 활동 캐릭터 목록에서 제외되며, 기존 방에서는 다른 활동 캐릭터로 변경할 수 있습니다.

## LOSTPARTY 업데이트 안내

Google 로그인과 원정대 인증을 기반으로 그룹·레이드 모집 기능을 이용할 수 있도록 이용 방식이 변경되었습니다.

**앱의 주요 기능을 이용하기 전에 아래 내용을 확인해주세요.**

### 기존 이용자 안내

서비스 구조가 크게 변경되어 부득이하게 **기존 사용자 데이터가 초기화되었습니다.** 기존에 이용하셨던 분들도 Google 로그인 후 계정 등록과 설정을 다시 진행해주세요.

기존 자료를 이어서 사용하지 못하게 된 점 양해 부탁드립니다.

### 처음 시작하는 순서

1. **Google 계정으로 로그인해주세요.** 주요 기능은 로그인 후 이용할 수 있습니다. 로그인 시 ‘로그인 유지’를 선택하면 다음 실행에서도 로그인을 유지할 수 있습니다.
2. **본인의 로스트아크 API 키를 등록해주세요.** 계정·캐릭터 정보를 조회하고 갱신하는 데 필요합니다. 원활한 이용을 위해 API 키를 먼저 준비해주세요.
3. **원정대를 등록하고 소유 인증을 진행해주세요.** 앱에서 안내하는 인증을 완료해야 해당 원정대의 캐릭터로 그룹과 레이드 모집·참가 기능을 이용할 수 있습니다.
4. **활동할 캐릭터와 참여 가능한 시간을 설정해주세요.** 사용할 캐릭터를 선택하고, ‘내 계정’에서 참여 가능한 시간을 설정하면 모집의 일정 조율에 활용할 수 있습니다.

### 주요 페이지와 기능

- **내 계정:** 원정대와 캐릭터를 등록·관리하고, 소유 인증과 활동 캐릭터 선택을 진행합니다. 레이드에 참여 가능한 시간도 설정할 수 있습니다.
- **레이드 현황:** 캐릭터별 주간 레이드 진행 상황을 확인하고 관리합니다.
- **레이드 모집:** 모집을 만들거나 원하는 조건의 모집을 찾아 참가할 수 있습니다. 모집 생성 시 출발 날짜와 시간을 설정하고, 참여자의 가능한 시간을 바탕으로 일정을 조율할 수 있습니다.
- **그룹:** 함께 활동할 그룹을 만들거나 가입하고, 그룹원과 그룹에 연결된 레이드 모집을 관리할 수 있습니다.
- **설정:** Google 로그인 상태와 로그인 유지 여부를 확인하고, API 키 등 이용에 필요한 설정을 관리합니다.

### 참여 가능한 시간을 활용한 일정 조율

**‘내 계정’에서 참여 가능한 시간을 미리 설정해주세요.**

모집의 시간 제안·자동 조율 기능에서 참여자의 가능한 시간을 활용해 함께 출발할 수 있는 시간을 찾을 수 있습니다. 모집의 출발 시간과 본인의 가능한 시간을 함께 확인해주세요.

### 금주·다음주, 두 주차를 함께 관리합니다

이제 **금주와 다음주를 구분해** 레이드 현황과 모집·일정을 관리할 수 있습니다.

이번 주 활동을 진행하면서 다음 주 모집과 일정도 미리 준비할 수 있습니다. **신청·참가하거나 시간을 설정할 때는 선택한 주차를 확인해주세요.**
