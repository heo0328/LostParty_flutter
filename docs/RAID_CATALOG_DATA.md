# RAID CATALOG DATA

## 데이터 기준

- 확인일: 2026-08-20
- 출처: 사용자가 인게임에서 확인해 전달한 현재 주력 레이드 정보
- 골드: 모든 관문 완료 기준
- `clearGold`와 `boundGold`는 별도로 동시에 지급되는 일반 골드와 캐릭터 귀속 골드
- 전달에서 생략된 골드 종류는 사용자 확인에 따라 `0`으로 기록
- 관문별 골드는 현재 모집 방식에서 사용하지 않음

## 파티 편성 기준

- 4인 파티마다 서포터 정확히 1명이 필요
- 동일한 딜러 직업은 한 파티에 최대 1명
- 딜러와 서포터의 직업명이 같아도 역할이 다르면 중복으로 보지 않음
- 8인 레이드는 4인 파티 2개이므로 동일 딜러 직업은 서로 다른 파티에 최대 2명 가능
- 8인 레이드는 서포터 총 2명, 4인 레이드는 서포터 총 1명까지만 모집
- 카탈로그는 전체 수용 한도를 제공하고, 실제 파티별 배치와 가입 가능 판정은 모집 상태 머신에서 처리

## 표시와 필터

- 상위 필터는 난이도를 제외한 `displayName` 사용
- 하위 필터는 선택한 레이드의 난이도 사용
- 모집 카드 표시는 `레이드 - 난이도 (표시 별칭)` 형식
- 캐릭터 아이템 레벨이 난이도의 `minItemLevel` 이상일 때 입장 조건을 만족
