|---|---|

| 목록에 보여줄 것 | 신청 당시 이름·직업·신청 역할, 신청 Snapshot의 아이템 레벨·전투력, 로컬 카탈로그로 판별 가능한 주요 시너지(항상 채용·공통 효과). |

| 누락·미확인 | 과거 신청의 수치/특성 누락은 미확인으로 남긴다. 0이나 임의 특성으로 채우지 않는다. |
| 선택 채용·서포터 | 선택 채용을 실제 보유로 단정하지 않는다. 서포터는 딜러 시너지 필터/슬롯 대상에서 제외한다. |
| 이번 승인에 포함하지 않는 것 | 최소 특성 요약 스키마, 전체 Armory 원문 업로드, 신규 Rules, 신청/기록 필터, 시너지 슬롯 조건, 전 직업 빌드 판별. |
